# BhoomiAI Roadmap

## v0.1.x — Open-source foundation
- core agriculture security reference modules
- recommendation-safety checks
- role-based access control
- privacy-aware logging
- synthetic benchmark cases and validation
- unit tests and release-readiness automation
- maintainer documentation

## v0.2.x — Integrated evaluation
- structured benchmark evaluator across security modules
- benchmark metrics and report generation
- configurable quality thresholds
- regression baselines
- command-line utilities for validation and evaluation

## v0.3.x — Domain depth
- broader synthetic scenarios across crop health, soil, weather, market and FPO workflows
- provenance and integrity checks for advisories and field observations
- stronger geospatial privacy controls
- multilingual public-safe test fixtures
- documented threat model and security architecture

## Longer term
- stable public interfaces and packaging
- reproducible evaluation bundles for researchers and contributors
- expanded community contribution workflow
- carefully reviewed integrations that preserve farmer privacy, human oversight and local agronomic requirements
