# Security Policy

BhoomiAI welcomes responsible reports about security issues affecting the public open-source project.

## Sensitive Information

Do not include passwords, API keys, authentication tokens, private keys, production secrets, identifiable farmer information, confidential farm records, restricted commercial data, or other sensitive material in public issues, pull requests, benchmark cases, examples, or logs.

## Reporting

For a suspected vulnerability, contact the maintainers privately through Optficial Labs before publishing technical details that could expose users or systems to harm.

Please include:

- affected component
- reproducible description using synthetic or public-safe data
- expected and observed behaviour
- potential impact
- suggested mitigation, if known

## Scope

The repository contains reference components and development benchmarks. A passing test or benchmark result is not a security certification, production-readiness guarantee, agronomic approval, or regulatory approval.
